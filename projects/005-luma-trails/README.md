# Luma Trails — Day 5

Fictional boutique safari and experiences planner in Livingstone, Zambia. All business details, contacts, prices, schedules and customer stories are illustrative. No booking is made and no real business is represented.

## Pages
- index.html — home and brand storytelling
- experiences.html — four sample excursions and enquiry links
- journeys.html — 1-, 2- and 3-day sample itineraries
- field-guide.html — seasonal notes, visitor tips and FAQ
- contact.html — trip-brief builder with copy-to-clipboard

## Fictional business brief
Positioning: thoughtful, locally grounded small-group trips with practical logistics and an unhurried pace. Service area: Livingstone/Victoria Falls and pre-arranged regional excursions. Fictional email: hello@lumatrails.example; fictional phone: +260 000 000 000; fictional booking desk, Livingstone. No licence or real address is claimed.

## Assets and dependencies
Original local SVG illustrations and logo. CSS uses system fonts. No external scripts, images or runtime dependencies. Field-guide links point to official/public reference pages.

## Preview
Run python3 -m http.server 8000 from this directory, then visit http://localhost:8000. Relative links make the folder independently deployable on GitHub Pages.
