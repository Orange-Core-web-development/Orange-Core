# COMMON FORM Clay Studio — Day 6

Fictional ceramics studio and clay club in Lusaka, Zambia. Business details, contacts, prices, class formats, testimonials and policies are invented.

## Pages
- index.html — studio introduction and featured sessions
- workshops.html — six class formats with category filters
- membership.html — sample studio-credit plans and working cost-comparison slider
- studio.html — studio story, practical notes and FAQs
- booking.html — enquiry form that builds and copies a summary locally

## Business brief
COMMON FORM welcomes beginners, hobby makers, friends, families and private groups. It offers wheel throwing, hand-building, short courses, glaze exploration, group sessions and studio credits.

Fictional contacts: hello@commonform.example; +260 000 000 000. Location is described only as Lusaka, Zambia; no real address is claimed.

Sample rates (illustrative): First spin wheel taster K450/person; Shape & story hand-building K350/person; Finding the centre four-session course K1,600; Colour play glaze K300/person; Clay together private group from K2,800; Little makers adult-child K500/pair; four studio credits K1,400/month; eight credits K2,400/month.

## Preview
From this folder run:

    python3 -m http.server 8000

Then open http://localhost:8000. No package install or build is required. Relative paths suit a static GitHub Pages deployment.

## Assets and licences
Four SVG assets are original artwork created for this concept. No external images, icon packages, font downloads or JavaScript libraries are used. System fonts keep it offline-friendly. No attribution is required for the original artwork.
