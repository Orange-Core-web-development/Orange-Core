# PAWLINE Veterinary Studio — Day 8

A fictional companion-animal clinic website concept for Lusaka. All business details, contact information, staff, hours, testimonials, policies and services are invented for portfolio demonstration. No licence, registration, real medical team, emergency service, or appointment availability is claimed.

## Source package
The complete multi-page HTML/CSS/JS and original SVG source is supplied as a downloadable package with this project. The repository includes the research and implementation notes; source archive mirroring is pending binary transfer in this environment.

## Pages
- Home — clinic story and care overview
- Care — preventive, vaccination, diagnostics, dental, surgery and nutrition categories
- Our people — fictional profiles
- First visit — interactive preparation checklist and local enquiry-summary builder
- Contact — demo contact details, FAQs, emergency guidance and licence-verification reminder

## Preview
Extract the source package and run `python3 -m http.server 8000` from the extracted project folder. Open `http://localhost:8000`. It is static, relative-path and GitHub Pages compatible.

## Assets & interactions
Original hand-authored SVGs created for this portfolio (CC0/self-created; attribution not required). No third-party runtime dependencies. Mobile navigation, reveal-on-scroll, care filters, checklist, local enquiry summary and copy control. The form does not send data or persist it.

## QA
Static checks passed for HTML references, IDs, JavaScript syntax, CSS brace balance and SVG XML. Manual browser/mobile testing and live deployment remain outstanding.
