# Day 15 website source package

The complete, self-contained website source is delivered in the Day 15 archive: **day15-foldline-packaging.zip**.

The archive contains seven HTML pages, shared CSS and JavaScript, five original SVG assets, this research report, the fictional business brief, asset/licence notes and QA checklist.

The ZIP is a run attachment rather than a repository binary. The documentation and catalogue are committed in this directory; the source archive can be unpacked directly into a repository root or `/docs` folder for an independent GitHub Pages deployment.

Local preview after extraction:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.
