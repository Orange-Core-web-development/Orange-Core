# Day 16 website source package

The complete seven-page static website is delivered in the Day 16 run attachment: **day16-tallyway-cargo.zip**.

Extract the archive to obtain the runnable `016-tallyway-cargo/` directory containing all HTML pages, CSS, JavaScript, SVG assets, research, README, QA and asset notes.

To preview:
```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` from inside the extracted folder.

The archive is attached to the conversation deliverable; it has not been committed as a binary ZIP in this repository. Original SVG artwork is also mirrored in this project directory.
