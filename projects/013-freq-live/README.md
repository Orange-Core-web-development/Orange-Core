# FREQ. Live Systems — Day 13

**Niche:** Live event technical production and staging.  
**Fictional base:** Makeni, Lusaka, Zambia.  
**Tagline:** Make the room feel something.

> FREQ. is a fictional portfolio concept. Business details, contacts, location, team, inventory, projects, testimonials and policies are invented. It is not a real production supplier.

## Pages
- `index.html` — positioning, capabilities, event formats and fictional work.
- `services.html` — filterable audio, lighting, stage/rigging, video, power and show-operations catalogue.
- `formats.html` — corporate, conference, festival, brand activation and private-event pathways.
- `work.html` — three fictional production case studies.
- `approach.html` — discovery, site review, technical design, pre-production, show-call, strike and readiness notes.
- `brief.html` — local technical-brief builder with validation, copy and TXT download.

## Complete source package
The complete six-page HTML/CSS/JavaScript website and five original SVG assets are delivered in `day13-freq-live.zip` with research, README, QA and asset/licence notes. Extract the archive to obtain the runnable `013-freq-live/` folder.

## GitHub Pages
All paths are relative. For standalone publication, copy the folder contents to a dedicated repository root or a configured `/docs` publishing directory. GitHub Pages does not publish an arbitrary nested project folder by default without a deployment workflow.

## Interactions
Responsive navigation; service and format filters; scroll reveals with reduced-motion fallback; project-brief validation and local summary; copy-to-clipboard; TXT download; native FAQ disclosures. The brief builder sends no data and has no backend.

## Fictional brief
FREQ. is imagined as a technical event-production studio based in Makeni, Lusaka, serving Lusaka and selected Zambian destinations by project arrangement. Proposed disciplines include audio, lighting, modular staging and rigging coordination, LED/video, temporary power planning, technical direction, operators and show crew.

**Fictional contacts:** `hello@freq.example`, `+260 000 000 000`.  
**Fictional proof:** Case studies are explicitly labelled as concept studies, not client projects.

## Limitations
The website is not a safety plan, technical specification, quote or permit application. Final rigging, temporary structures, electrical distribution, crowd/site design and emergency arrangements require competent people, venue coordination and applicable local approvals. HSE/Event Safety Alliance links are reference guidance, not Zambian legal advice. No real licences, insurance, certifications, inventory, client relationships or performance records are claimed. See `research.md` and the source archive for the complete brief and QA.
