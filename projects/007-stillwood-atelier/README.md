## Assets/licensing
All SVG assets are original artwork created for this portfolio demonstration. No external font, stock photo or third-party JS/CSS library is used. No attribution is required beyond retaining this project context. SVGs are illustrations, not photos of completed jobs.

## Preview and deployment
Run from this directory: python3 -m http.server 8000, then visit http://localhost:8000. Relative paths allow static hosting. GitHub Pages must serve the project directory or copy it to the publish folder.
