# Three.js (`three`)

- **Use:** Interactive 3D objects, vehicles, environments and WebGL scenes.
- **Install in a project that needs it:** `npm install three`
- **Official docs:** https://threejs.org/docs/
- **Source:** https://github.com/mrdoob/three.js
- **License:** MIT (verify the selected release and any separately sourced 3D assets).
- **Considerations:** WebGL capability, model/texture download size, GPU and mobile performance; provide a fallback for unsupported devices and keep model asset licences separate.
- **Status:** Conditional — candidate only. Check the current stable package version, browser support and asset rights before use; commit the project lockfile.
