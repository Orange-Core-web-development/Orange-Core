# 3D and WebGL

Research target: 12 entries.

Investigate JavaScript 3D engines, model loaders, controls, rendering helpers and optimisation tools.

Asset sources are documented separately from code libraries. Prefer downloadable GLB/GLTF assets with explicit commercial-use permissions. Record each asset's author, source, licence, attribution requirements, file size and included animations.

Do not assume a 3D model is commercially reusable just because it can be downloaded for free.
