# Leaflet (`leaflet`)

- **Use:** Interactive maps.
- **Install in a project that needs it:** `npm install leaflet`
- **Official docs:** https://leafletjs.com/reference.html
- **Source:** https://github.com/Leaflet/Leaflet
- **License:** BSD-2-Clause (verify the selected release).
- **Considerations:** Leaflet is the map renderer, not a tile or geocoding service. Choose a provider and confirm its terms, attribution, quotas and costs; do not assume public OpenStreetMap tile servers are an unrestricted production service. Provide an accessible non-map alternative where appropriate.
- **Status:** Conditional — verify current version, provider terms and deployment requirements before adoption; commit the project lockfile.
