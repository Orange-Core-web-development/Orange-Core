# Lenis (`lenis`)

- **Use:** Smooth scrolling.
- **Install in a project that needs it:** `npm install lenis`
- **Official docs:** https://lenis.studiofreight.com/
- **Source:** https://github.com/darkroomengineering/lenis
- **License:** MIT (verify the selected release).
- **Considerations:** Smooth scrolling can interfere with expected browser behavior, accessibility and performance. Test touch devices, keyboard navigation, anchor links and reduced-motion settings; native scrolling may be preferable.
- **Status:** Conditional — verify current package version and integration guidance before adoption; commit the project lockfile.
