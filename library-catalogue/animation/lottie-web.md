# Lottie Web (`lottie-web`)

- **Use:** Playback of vector animations exported as Lottie JSON.
- **Install in a project that needs it:** `npm install lottie-web`
- **Official docs:** https://airbnb.io/lottie/#/web
- **Source:** https://github.com/airbnb/lottie-web
- **License:** MIT for the player; verify licences and usage rights for each animation asset separately.
- **Considerations:** Animation JSON and runtime can affect page weight and rendering cost. Provide a static or accessible alternative and avoid essential information conveyed only by animation.
- **Status:** Conditional — check current package version and asset provenance before adoption; commit the project lockfile.
