# GSAP (`gsap`)

- **Use:** Advanced timelines, sequencing and coordinated animation.
- **Install in a project that needs it:** `npm install gsap`
- **Official docs:** https://gsap.com/docs/
- **Source:** https://github.com/greensock/GSAP
- **License:** GreenSock license; review current terms at https://gsap.com/licensing/, especially for commercial use and any plugins.
- **Considerations:** Prefer transform/opacity animation, clean up timelines when views are removed, and respect reduced-motion preferences.
- **Status:** Conditional — check current package version and licensing terms before adoption; commit the project lockfile.
