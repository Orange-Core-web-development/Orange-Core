# Anime.js (`animejs`)

- **Use:** Alternative JavaScript animation for DOM elements and SVG.
- **Install in a project that needs it:** `npm install animejs`
- **Official docs:** https://animejs.com/documentation/
- **Source:** https://github.com/juliangarnier/anime
- **License:** MIT (verify the selected release).
- **Considerations:** Compare capabilities and bundle cost with native CSS/Web Animations API and any existing animation dependency; support reduced motion.
- **Status:** Conditional — check current stable version and package API before adoption; commit the project lockfile.
