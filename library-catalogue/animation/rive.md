# Rive Web Runtime (`@rive-app/canvas`)

- **Use:** Interactive animated graphics with state-machine-driven input.
- **Install in a project that needs it:** `npm install @rive-app/canvas`
- **Official docs:** https://rive.app/docs/runtimes/web
- **Source:** https://github.com/rive-app/rive-wasm
- **License:** Review the runtime package licence and Rive terms for the chosen runtime and assets; do not assume artwork/runtime permissions are identical.
- **Considerations:** Canvas rendering may not expose animation content to assistive technology; provide equivalent text or controls and test runtime size, mobile performance and reduced-motion behavior.
- **Status:** Conditional — confirm the currently recommended web runtime package, version and commercial terms before adoption; commit the project lockfile.
