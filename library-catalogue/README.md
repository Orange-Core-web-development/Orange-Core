These are research targets, not mandatory installations. Record native browser APIs separately because they do not require package installation.

## Entry checklist

For each candidate, document:

1. Purpose and key capabilities
2. Vanilla JavaScript compatibility
3. Official documentation and source repository
4. Current version and date checked
5. Licence and commercial-use conditions
6. Installation command and basic usage example
7. Dependencies and compatibility concerns
8. Bundle/performance and mobile considerations
9. Accessibility and reduced-motion considerations
10. Maintenance status, alternatives and recommended use cases

## Status labels

- **Approved:** reviewed and suitable for the intended use.
- **Conditional:** useful with documented limitations or restrictions.
- **Avoid:** unsuitable, unmaintained or licensing-risky for our use.

Always verify current licence terms and package details before installation or client use.
