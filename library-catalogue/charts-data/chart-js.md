# Chart.js (`chart.js`)

- **Use:** Charts and data visualisation.
- **Install in a project that needs it:** `npm install chart.js`
- **Official docs:** https://www.chartjs.org/docs/
- **Source:** https://github.com/chartjs/Chart.js
- **License:** MIT (verify the selected release).
- **Considerations:** Keep chart bundles and datasets appropriate to the page. Provide an accessible text/table equivalent; a canvas chart alone may not communicate data to assistive technology.
- **Status:** Conditional — check current stable version, required adapters and accessibility needs before adoption; commit the project lockfile.
