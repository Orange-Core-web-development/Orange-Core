# Howler.js (`howler`)

- **Use:** Audio playback and sound effects.
- **Install in a project that needs it:** `npm install howler`
- **Official docs:** https://howlerjs.com/
- **Source:** https://github.com/goldfire/howler.js
- **License:** MIT (verify the selected release; audio asset rights are separate).
- **Considerations:** Browser autoplay restrictions apply. Start playback only after user interaction, provide controls and fallback behavior, and avoid audio that plays unexpectedly.
- **Status:** Conditional — check current stable version, browser support and media licences before adoption; commit the project lockfile.
