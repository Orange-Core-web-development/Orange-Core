# Swiper (`swiper`)

- **Use:** Responsive sliders and carousels, including touch interaction.
- **Install in a project that needs it:** `npm install swiper`
- **Official docs:** https://swiperjs.com/
- **Source:** https://github.com/nolimits4web/swiper
- **License:** MIT (verify the selected release).
- **Considerations:** Import only required modules/styles. Ensure keyboard operation, accessible slide labels and controls, pause behavior for automatic movement, and reduced-motion support.
- **Status:** Conditional — check current package version and accessibility behavior before adoption; commit the project lockfile.
