# Repository Documentation

Repository-wide standards and workflows belong here.

Planned documentation:

- Project structure and naming
- Dependency and version policy
- Licensing and asset provenance
- Accessibility and reduced-motion standards
- Mobile performance checklist
- Testing and quality checks
- Static hosting and deployment notes

## Dependency policy

Keep dependencies inside the independent project that uses them. Prefer exact, reviewed versions and commit lockfiles. Avoid mandatory paid services, paid plugins, subscriptions and paid assets. A free tier is not automatically unlimited or suitable for commercial use.
